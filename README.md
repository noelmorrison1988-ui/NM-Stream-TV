# NM Stream Approver — Android

Direct-sideload Android wrapper for the NM Stream TV Account / Approver site.

- Site: https://nm-stream-tv-account.floot.app/
- Package: `za.co.nmstream.approver`
- App name: **NM Stream Approver**
- Persistent cookies/session
- DOM/local storage
- Android back-button navigation
- File chooser support
- HTTPS-only network policy

GitHub Actions builds a debug-signed APK suitable for direct installation on Android devices.
